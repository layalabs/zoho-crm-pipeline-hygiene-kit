# Privacy Policy

Effective date: 1 November 2026

Pipeline Hygiene for Zoho CRM runs inside the installing customer's Zoho CRM organization.

The extension reads Deal fields and related Tasks, Events, and Calls. It uses this data to create daily pipeline hygiene email digests inside Zoho CRM.

The extension does not send CRM data to Laya Labs or another external service. It does not use an external database. It does not collect analytics or telemetry.

Zoho CRM processes the data under the customer's Zoho agreement and settings. The customer controls CRM access, retention, email delivery, audit logs, and extension removal.

The extension stores one CRM organization property named `Enabled`. This property contains only `true` or `false`.

The extension source is public at https://github.com/layalabs/zoho-crm-pipeline-hygiene-kit. Users can report a privacy concern through the repository issue tracker.

If a later version adds external storage, telemetry, or another data processor, this policy will change before that version is released.
